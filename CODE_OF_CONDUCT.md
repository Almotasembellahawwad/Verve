# Community code of conduct

Verve welcomes thoughtful disagreement about design, engineering, and product direction. Participation must remain respectful, specific, and safe.

- Critique work and evidence, not people.
- Do not harass, threaten, discriminate, or publish private information.
- Never post API keys, private prompts, confidential generated code, or exploit details in public issues.
- Maintainers may edit, hide, or remove contributions that put people or systems at risk.

Report conduct concerns privately to the repository owner. Security concerns belong in a private GitHub security advisory.
